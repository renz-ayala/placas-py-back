# CRUD para la consulta de placas con impresión de reporte

Desarrollado con :
* **Python**
* **FastApi**
---

## Requisitos Previos
* Copiar el archivo .env.template, reemplazar por el nombre .env
* Configurar las variables con su propia BD.
* Puede ver las entidades en la capa de infraestructura, para modelar su bd.
---
### Pasos para ejecutar en local.
1. Abrir el proyecto en un IDE como PyCharm.
2. Ejecutar en su consola, asegurarse de estar en el entorno <venv> y haber instalado las dependencias
```bash
$ python main.py
```
